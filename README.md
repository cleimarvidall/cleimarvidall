### 🧠 Sobre Mim

Antes de ser um engenheiro colado em uma stack específica, eu sou um **desenvolvedor focado em resolver problemas reais**. Acredito que um bom código deve ser limpo, de fácil manutenção e, acima de tudo, entregar valor. 

Transito com naturalidade entre diferentes ecossistemas porque entendo que cada desafio exige uma abordagem única. Não me apego a dogmas tecnológicos: se a missão exige robustez estruturada, escalabilidade absurda ou prototipagem rápida, eu sei exatamente qual linguagem tirar da bainha.
